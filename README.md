# Мировое господство

Цифровая версия настольной игры: приложение ведущего (ПК и Android) и
Telegram-бот для игроков.

- [Правила](docs/RULES.md)
- Правила для игроков: [HTML](miniapp/rules.html) · [PDF](miniapp/rules.pdf)
- Хард-режим: [правила](docs/HARD_RULES.md) · [HTML](miniapp/hard-rules.html) · [PDF](miniapp/hard-rules.pdf)
- [План разработки](docs/PLAN.md)
- [Карта проекта и устройство кода](docs/ARCHITECTURE.md)

## Структура

```
core/     — правила игры на Kotlin (без UI)
bot/      — Telegram-бот (работает внутри приложения ведущего)
app/      — интерфейс приложения ведущего (Compose Multiplatform), запуск на ПК
androidApp/ — запуск на Android
legacy/   — Python-версия 1.0.0 (PyQt6)
```

## Сборка

Нужен JDK 17+.

```bash
./gradlew :app:run                # запустить приложение ведущего
./gradlew :core:jvmTest :bot:jvmTest   # тесты ядра и бота
./gradlew :app:desktopTest        # скриншоты экранов → app/build/screenshots
./gradlew :app:packageDistributionForCurrentOS   # установщик для текущей ОС → app/build/compose/binaries/main
./gradlew :androidApp:assembleRelease            # APK → androidApp/build/outputs/apk/release
./gradlew :androidApp:installRelease             # установить на подключённый телефон
```

## Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. В приложении: Меню → Настройки → вставьте токен → «Проверить» → «Сохранить».
3. В партии на панели «Telegram-бот» нажмите «Запустить».
4. Кнопкой «Ссылка» скопируйте приглашение для каждой страны и отправьте игроку.
   Игрок открывает ссылку и становится главой страны.

Сервер не нужен: бот работает, пока запущено приложение ведущего. На Android
он продолжает работать в фоне (уведомление «Telegram-бот принимает приказы»).

Бот должен работать только на одном устройстве: иначе часть сообщений уйдёт в
партию на другом устройстве, а игроки получат ответ «Вы не глава страны».

## Мини-приложение

Страница `miniapp/` публикуется на GitHub Pages.

## Параметры и журнал партии

Меню → Настройки → Параметры игры: цены, доходы, экология, стартовые ресурсы и
доклады. Сохраните значения для новых партий или примените к открытой партии
при пустой очереди и без активного события. Вкладка «Лог» содержит ручной выбор
события и кнопку «Копировать полный лог» для отправки игрокам после партии.

## Обновление правил для игроков

Кнопка «?» в мини-приложении открывает правила поверх приказов, не сбрасывая очередь.
Исходный текст — `docs/PLAYER_RULES.md`. После редактирования пересоздайте обе версии:

```bash
# Нужны Python-пакет Markdown и LibreOffice (команда libreoffice).
python3 scripts/build_player_rules.py
```

Результат: `miniapp/rules.html` и `miniapp/rules.pdf`. Они публикуются вместе с
мини-приложением на GitHub Pages. Для изменения страницы правил пересборка APK не нужна.

## Режимы игры

При создании партии выберите «Классический» или «Хард». Старые сохранения
открываются как классические; переключать режим открытой партии нельзя.

Хард: ровно 5 стран по 4 города, названия редактируются при создании партии, по умолчанию 6 раундов (1–100 выбирается при создании). Победа по
среднему уровню жизни, затем развитию и бюджету. Доступны инвестиции, санкции,
восстановление, помощь ООН, содержание бомб и мгновенные переводы. Деньги
округляются до целого. Параметры: Настройки → Параметры хард-режима.

Бот поддерживает оба режима. Для инвестиций и экологии в хард-режиме он запрашивает
сумму сообщением. Мини-приложение автоматически открывает `hard.html` по состоянию
партии; кнопка «?» показывает отдельную справку. Перед мгновенным переводом
отправьте изменённую очередь и заново откройте свежую кнопку приказов.

Новая версия APK требует публикации всей папки `miniapp/`, включая `hard.js`,
`hard.html` и `hard-rules.*`. Номер партии проверяется при отправке приказов
хард-режима; старые ссылки другой партии не принимаются. Для ручной проверки
`:bot:jvmTest` создаёт `bot/build/hard-miniapp-sample-url.txt`.

Скрипт `scripts/build_player_rules.py` теперь создаёт правила обоих режимов:
из `docs/PLAYER_RULES.md` и `docs/HARD_RULES.md`.
